Features

Built for the way AI power users work

Modern AI work is rarely one-chat-at-a-time. AI Multiplexer gives you a terminal-multiplexer style workspace — without the tab chaos.

Multi-pane AI workspace

Split one desktop window into focused panes. Use Focus, 2-column, 3-column, or 4-column layouts, then drag panes into the order that matches your workflow.

Layouts: Focus · 2 · 3 · 4 columns

Profile-based session isolation

Profiles are real browser-session containers. Each profile has its own cookies, storage, cache, and login session — isolated on disk per profile, so accounts stay signed in without leaking into each other.

Per-profile data_directory on disk

Tabs inside every pane

Each pane holds multiple tabs with their own URL, title, favicon, and loading state. Reorder tabs, move tabs between panes that share a profile, or detach a tab into a new pane.

Cross-pane drag requires matching profile

Native webviews, not fragile iframes

Many AI services block iframe embedding with CSP or X-Frame-Options. AI Multiplexer uses native Tauri child webviews, so those sites run like normal desktop browser surfaces.

Webviews keyed by tab — preserved across drags

Local-first state

Your workspaces, panes, tabs, profiles, theme, and layout are stored locally in localStorage. The app is a desktop shell for the services you choose — not a hosted proxy for your chats.

Debounced 500ms writes · flush on unload

Backup, restore & auto-update

Move layout and profile settings with config JSON, or protect local session data in an encrypted full backup. The app can restore legacy ZIP backups and check GitHub Releases for desktop updates.

Full backup v2 · encrypted · passphrase never stored

How AI power users use it

Model comparison
Open Claude, ChatGPT, Gemini, and Perplexity side by side and ask the same question. Compare responses in real time.
Research + drafting
Keep a research pane (Perplexity / Gemini) visible while another AI writes, edits, or summarizes in an adjacent pane.
Account separation
Use profiles with separate login sessions — all visible simultaneously in different panes, with no account conflicts.
Long-running prompts
Let one model think while you continue working in another pane. No more waiting or losing your place.
Project context
Keep dedicated workspaces for clients, repos, topics, or experiments. Switch entire contexts without closing anything.
Local tooling
Open localhost apps, docs, dashboards, or local AI tools beside hosted AI chats — any http/https URL works.

FAQ

Frequently asked questions

A local-first desktop application that runs multiple AI chat services side by side in a single window, using native Tauri webviews with per-profile session isolation. The only built-in profile is Default — you create additional profiles with any name you like.
Browser tabs get noisy and fragile. AI Multiplexer gives you persistent workspaces that survive restarts, profile isolation so accounts don't conflict, native webviews that handle X-Frame-Options and strict CSP, and a focused shell without browser chrome.
The New Tab page prelinks ChatGPT, Claude, Gemini, DeepSeek, Perplexity, and Grok. But since it's a general browser shell, any http/https URL works — including localhost tools, docs, and dashboards.
Windows 10/11 x64 with WebView2 Evergreen is the supported beta target. macOS and Linux artifacts are experimental and unsupported. Check the latest release notes before installing them.
